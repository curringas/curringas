# Curro Martínez Hidalgo

Project Manager y desarrollador full stack en Córdoba. Desarrollo webs y aplicaciones desde 2002, sobre todo con PHP, Laravel, React y Next.js, y me ocupo del producto completo: análisis, diseño de interfaz, desarrollo y trato con el cliente.

Desde 2025 trabajo como programador y jefe de proyectos de plataformas SaaS y de las apps móviles de sus usuarios. Antes fundé Cubiertas MTB, un ecommerce con desarrollo propio que se vendió en 2017 al grupo francés Lecyclo, y cofundé Palabrea, una empresa de desarrollo web y apps.

## Proyecto destacado

**[MotoCiudad](https://github.com/curringas/motociudad)** · [motociudad.com](https://motociudad.com) · [Google Play](https://play.google.com/store/apps/details?id=com.motociudad.app)

App para iOS, Android y web para encontrar, proponer y verificar parkings de moto, con una comunidad gamificada. Verificación in situ con GPS y foto, panel de administración y moderación de comentarios con IA. Proyecto final del máster AI4Devs, desarrollado con Claude Code y Spec Driven Development.

React Native + Expo · TypeScript · Supabase (PostgreSQL, PostGIS, Edge Functions) · Vitest, Playwright, Maestro, pgTAP · GitHub Actions + EAS
